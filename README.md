# 智慧政务通应用原型

这是一个政务系统移动应用的高保真原型，使用HTML、Tailwind CSS和JavaScript开发。

## 功能页面

- **登录页面**：用户登录界面
- **首页/服务大厅**：展示热门服务、政策资讯和待办事项
- **我的办事**：包含待办事项、办事记录和便捷入口
- **资讯页面**：展示政策文件、通知公告和办事指南
- **在线咨询**：提供智能问答、人工客服和热线电话服务
- **个人中心**：展示用户个人信息和相关服务
- **设置页面**：提供账号安全、通知设置等功能

## 技术栈

- HTML5
- Tailwind CSS
- Font Awesome图标
- 原生JavaScript

## 如何使用

1. 克隆或下载本仓库
2. 在浏览器中打开index.html文件
3. 浏览不同页面的UI设计和交互效果
